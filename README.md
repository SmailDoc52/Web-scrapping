# Домашнее задание «Веб-скрапинг» (Решение)

Этот проект парсит страницу со свежими статьями на [Хабре](https://habr.com/ru/all/) и выбирает те статьи, в которых встречается хотя бы одно из ключевых слов.

## Установка зависимостей

**Убедитесь, что у вас установлены следующие зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

## Запуск скрипта

**Запустите скрипт `main.py`:**
   ```bash
   python main.py
   ```

## Описание работы скрипта
1. Скрипт получает HTML-страницу с URL, указанном в переменной окружения.
2. Парсит страницу и извлекает статьи из секции `article.tm-articles-list__item`.
3. Проверяет наличие ключевых слов в тексте и заголовке каждой статьи.
4. Если найдено совпадение, выводит дату, заголовок и ссылку на статью.

## Примечание
Изначально создал файл для хранения переменных окружения `tools/constants.py` и использовал библиотеку `python-dotenv` для хранения `url`, но так как не знаю, как работает автоматический скрипт проверки (ИИ), решил все переменные записать в основной файл скрипта `main.py`.
